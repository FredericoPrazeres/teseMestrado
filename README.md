# teseMestrado — CI/CD Tools Replication Package

> **Looking for how to reproduce the experiments?** Start at [REPLICATION_GUIDE.md](REPLICATION_GUIDE.md) — it is the entry point for this whole repository and links out to every other guide (methodology, runner setup, resource consumption experiment, execution time experiment).

This repository accompanies the thesis comparing **GitHub Actions**, **GitLab CI/CD**, **Azure Pipelines**, and **Jenkins**. It contains:

- The experimental methodology ([methodology.tex](methodology.tex)).
- Setup instructions for the [Cloud Microservices Application](CLOUD_MICROSERVICES_APP.md), the target app used in the resource consumption experiment.
- Runner installation/registration instructions ([RUNNERS_SETUP.md](RUNNERS_SETUP.md)).
- Instructions to run the containerized resource consumption experiment ([RESOURCE_CONSUMPTION_EXPERIMENT.md](RESOURCE_CONSUMPTION_EXPERIMENT.md)).
- Consolidated pipeline definitions for the execution time experiment ([execution-time-experiment/](execution-time-experiment/README.md)).

See [REPLICATION_GUIDE.md](REPLICATION_GUIDE.md) for the full repository map and a suggested reading order.
